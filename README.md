# Emerging_Technologies-Silver_Milk

Team Silver Milk's shared integration workspace for MASY1-GC 1800 Emerging Technologies.

**Members:** Dian Li, Justin Zhong, Karuna Srivastava, Nini Huang, Yuanxiang Zhang

This repository holds the **team-approved** specialist agents (Labs 3–9), the final mixture-of-experts system (Labs 10–11), and the semester records. It is a working copy. It does not replace or alter the frozen Brightspace scaffold ZIP. Individual candidate agents stay in each member's personal repository until the team promotes them.

## Layout

| Path | Contents |
|---|---|
| `docs/team_agent_standard.md` | Team Agent Design and Integration Standard (Team Lab 2) |
| `records/` | Decision log, agent inventory, test & failure log, evidence register, integration issue log, contribution record |
| `records/evidence/` | Saved test artifacts referenced by the logs |
| `scaffold/` | Placeholder for the unchanged ET scaffold working copy (see its README) |
| `agents/` | Team-approved specialists only, promoted per the standard, Section 6 |

## Public-repo rule

This repo is public. Instructor materials (course PDFs, rubric, lab instructions, scaffold ZIPs, data files) are excluded by `.gitignore` and must not be committed. Share them through Brightspace or the team drive.
